# Security policy

## Supported versions

Security fixes are provided for the latest released version only.

## Reporting a vulnerability

Please use GitHub's **Private Vulnerability Reporting** feature for
[`mayurmhjn/iaclineage`](https://github.com/mayurmhjn/iaclineage/security/advisories/new). Do not report security vulnerabilities through public
GitHub Issues.

Include the affected version, a minimal safe reproduction, impact, and any
suggested mitigation. Do not include credentials, real Terraform source, state,
plans, or reports containing opted-in source values.
